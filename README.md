# Koi Life Simulator

Initial Godot 4 project scaffold for Android.

## Current scope
- Home screen with a placeholder for the main character image.
- Bottom navigation: Map, Job, Karakter, Profil.
- Simple placeholder pages for each menu.
- Character art will be added later by the project owner.

## Intentionally not included
- No eye animation.
- No extra gameplay systems or features beyond the agreed initial screens.

## Open in Godot
Open this folder as a Godot project and run `scenes/main.tscn`.
